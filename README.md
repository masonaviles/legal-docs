# Legal documents — Tanuki Tech

Public home for the privacy policies of Tanuki Tech browser extensions.

This repository exists so the policies have stable public URLs. The Chrome Web
Store requires a reachable privacy policy URL, and re-checks it on every
extension update — not just at first submission.

## Notes for future me

- **Keep this repository public.** A 404 on any policy URL blocks Chrome Web
  Store updates for the extension it belongs to.
- **Do not rename files** once a URL is live in a store listing. Add new files
  for new extensions instead.
- When a policy changes materially, update its "Last updated" date and make sure
  the corresponding store listing's data disclosures still match what it says.
